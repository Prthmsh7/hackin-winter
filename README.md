# Hackmate

This repository contains our project for the Hackin-winter hackathon at JIIT.

## Features

- **Collaborative IDE (Integrated Development Environment)**  
  A real-time, collaborative coding environment for students and teachers to code together.

- **Collaboration Features**  
  - **Chat**: Real-time messaging to discuss ideas and code.  
  - **Video Conference**: Live video calls for more interactive teaching and learning.  
  - **Whiteboard**: Draw and explain concepts visually during sessions.

- **Escrow-based Payment System**  
  Payments are securely handled via an escrow system where the student pays upfront, and the teacher receives payment at the end of the session.

- **Dashboard**  
  A user-friendly dashboard for tracking progress, sessions, and payments.

## Project Overview

The **Hackmate** platform enables teachers and students to collaborate seamlessly through various tools designed for technical learning. It includes a real-time collaborative IDE, communication tools like chat and video conferencing, and an intuitive dashboard to manage the learning experience.

### How it Works:

- **Collaboration**: Multiple people can join the same session, but initially, the collaboration is limited to 2 participants unless the payment is made upfront.
  
- **Teacher-Student Interaction**:  
  - The teacher teaches coding concepts or works on a project with the student.  
  - The student makes an initial payment to book the session, and after the session concludes, the teacher receives the payment.

- **File Uploading**:  
  Students and teachers can upload and share files during their sessions for efficient learning and project work.
